## 🧭 Overview

Prose Metrics is a small, local-first utility. Measure text structure and estimate readability offline. It runs on your machine and does not require an account or hosted service.

## ✨ Features

- ✨ Count characters, words, sentences, and paragraphs.
- ✨ Estimate average sentence length and reading time.
- ✨ Calculate an approximate Flesch Reading Ease score for English text.
- ✨ List frequent content words and export JSON.
- ✨ Read a UTF-8 file or accept piped input; no network access.

## 🎬 Demo

Run the included sample file, or pass your own UTF-8 text file. The readability score is an approximate heuristic and is intended for comparison, not as a definitive grade.

## 🚀 Quick Start

```bash
python main.py sample.txt
```

## 🧰 Tech Stack

- 🟢 Python 3 standard library
